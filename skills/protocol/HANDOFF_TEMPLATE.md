# Handoff

The handoff procedure is owned by [architect-handoff](../architect-handoff/SKILL.md). Write the handoff in the store that skill names. Do not keep a second copy.

The still-true fields that skill requires are the task URIs for the request, the requirements, the proposal, and the plan, plus the decisions, the open items, and the acceptance criteria. Copy those fields from the skill. Do not invent a filesystem path for the handoff.
