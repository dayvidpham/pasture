# Workflow

The generated skills own the procedure. This file keeps the headings those skills already link to, and does not restate the procedure.

A wave gate advances when no blocker is open. Convergence over open findings is at the end, not at each wave. Workers record evidence and do not close tasks. The supervisor closes after review. Those rules are in the supervisor and worker skills.
